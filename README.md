# Sehel Tech— AI Programming Mentor

[![Live Demo](https://img.shields.io/badge/Live_Demo-sehel--tech.lovable.app-00C7B7?style=for-the-badge&logo=vercel&logoColor=white)](https://sehel-tech.lovable.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

An intelligent, bilingual, student-centric programming education platform founded and curated by **Muhammad Sehel**. 

Sehel Tech pairs an interactive, real-time AI mentor with curated programming courses, a code scratchpad, and a local-first study notebook designed for aspiring software engineers and data analysts.

---

## 🌟 Key Features

- **🤖 24/7 AI Code Mentor:** Real-time conversational AI tutor trained to debug syntax, explain algorithms, and guide students through code in both **English** and **Roman Urdu**.
- **📚 Curated Learning Paths:** Focused modules on Python, C++, Data Structures & Algorithms (DSA), Web Development, and AI fundamentals.
- **📝 Student Notebook & Scratchpad:** In-browser scratchpad for drafting code notes, testing logic, and tracking daily study milestones.
- **🔒 Privacy-First / On-Device Storage:** User profiles, study notes, and chat history are saved 100% locally in the student's browser (`localStorage`). No tracking or cloud storage of student notes.
- **🎨 Responsive Modern UI:** High-tech cyber aesthetic with instant Dark/Light mode toggle, optimized for smartphones, tablets, and desktop workstations.

---

## 🛠️ Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) (Full-stack React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with custom cyber design tokens
- **Icons & Components:** Lucide Icons & Radix UI primitives
- **AI Engine:** Lovable AI Gateway streaming completions
- **State & Storage:** Local-first client storage (`localStorage`)
